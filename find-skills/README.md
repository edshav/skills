# find-skills

Helps the agent discover and install skills from the open agent skills ecosystem
(`npx skills find` / `npx skills add`, [skills.sh](https://skills.sh/)) when you ask
"how do I do X", "is there a skill for X", or want to extend what the agent can do.

## Install

```
/plugin install find-skills --marketplace edshav/skills
```

Or copy this folder into your agent's skills directory (e.g. `~/.claude/skills/find-skills/`).
