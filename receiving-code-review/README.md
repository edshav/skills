# receiving-code-review

Makes the agent verify review feedback against the code before applying it: restate, check,
push back with technical reasoning when a suggestion is wrong, implement one item at a time,
and skip performative agreement.

## Provenance

A verbatim copy of
[`obra/superpowers/skills/receiving-code-review/SKILL.md`](https://github.com/obra/superpowers/tree/main/skills/receiving-code-review)
at release `6.4.2`, redistributed under its MIT license (© 2025 Jesse Vincent, see
[LICENSE](LICENSE)). Extracted so it can be used without the rest of the superpowers plugin.
Changes upstream are not pulled automatically; to refresh, copy the file again and update the
release above.

## Install

```
/plugin install receiving-code-review --marketplace edshav/skills
```

Or copy this folder into your agent's skills directory (e.g. `~/.claude/skills/receiving-code-review/`).
